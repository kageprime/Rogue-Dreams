Architecture decisions made

  • Phaser mounted via next/dynamic with ssr: false to avoid window reference errors
  • GameClient component separated from page for clean dynamic import pattern
  • Fallback procedural generation used when LLM API is unavailable
  • All game state lives in Phaser scenes — React is just a shell
  • Sprite rendering uses geometric shapes — no sprite assets needed for MVP
  • Camera zoom set to 2x for retro feel
  • Weapon stats rotate per floor from a predefined pool

Known gaps Sprint 2 Candidates

  • LLM integration not wired — API falls back to procedural generation
  • No sound effects or music
  • Enemy variety limited to 2 types per run (pool of 4)
  • No minimap
  • No persistent save / progression
  • Weapon pickups not yet spawned as items on map
  • Touch/mobile not supported
