Architecture notes

  • Effects is a static utility class — no instantiation needed, just Effects.shakeCamera(scene, ...) style calls
  • AudioManager is wrapped in a singleton export const audio = new AudioManager() — imported and used directly
  • Sound uses Web Audio API oscillators — zero asset files, generates retro tones at runtime
  • Audio context is lazily created on first play (handles browser autoplay policy)
  • Mute toggle via audio.toggleMute() — not exposed in UI yet, ready for Sprint 6 settings menu
  • Sprite textures generated in BootScene via offscreen canvas → textures.addCanvas()
  • Enemy falls back to Rectangle if texture key doesn't match
  • Floor transition uses fadeOut → text scale animation → fadeIn sequence
