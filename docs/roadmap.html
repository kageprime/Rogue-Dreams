Project Roadmap

Six sprints to take Rogue Dreams from bare MVP to a polished, AI-powered roguelite. Each sprint builds on the previous — no skipping ahead.

Total epics: 7 Status: Sprint 1 done Sprint 2 current

Sprint 1: Foundation Done

Goal: Player can start a run, move, fight, reach exit, die, restart.

Core loop MVP — Next.js scaffold, Phaser game mount, title screen, player (WASD + shoot), 2 enemy types, chase AI, weapons, floor generation API, tile map rendering, collision, exit door, death/restart, HUD.

Sprint 2: Juice & Game Feel Current

Goal: Every action feels satisfying. Screen shake, particles, sound, polish.

Screen shake on hit/damage, hit flash (enemy + player), death particle burst, floor transition animation (fade + "Floor N" text), sound effects (shoot, hit, death, pickup, floor clear), damage numbers, sprite texture generation (render recipes to canvas), projectile trails.

Sprint 3: Content Depth Planned

Goal: More enemy types, bosses, items, map features.

Ranged enemies (projectile attacks), boss rooms every 3 floors, weapon pickups mid-run, passive items (speed boost, shield, multi-shot), minimap overlay, floor themes (color palettes per depth), enemy variety scaling with floor number.

Sprint 4: State Machine + Economy Planned

Goal: Proper scene flow, gold economy, shop between floors.

TitleScene (Phaser), PauseScene overlay, GameOverScene with stats, gold drops from enemies, gold counter in HUD, ShopScene between floors to buy items, scene wiring for death/exit/restart flows.

Sprint 5: LLM Integration Planned

Goal: Enemies, items, and lore generated by an LLM for infinite variety.

Wire real LLM API (OpenAI/Anthropic), sprite recipes from LLM descriptions, generated flavor text per floor, generated boss names/mechanics, item name puns, seed-based deterministic generation for sharing runs.

Sprint 6: Progression Planned

Goal: Runs have stakes and persistence. Players come back.

Persistent save (localStorage), meta-progression (unlock starting weapons/skins), run history stats (kills, deepest floor, time played, death count), achievement system, post-run summary screen.

Sprint 7: Polish & Ship Planned

Goal: Ready to share. Looks like a real game.

Animated title screen (parallax, animated ASCII), settings menu (volume, controls rebind, window mode), leaderboard (local scores), loading screen art, performance optimization, mobile-responsive touch controls (stretch), deployment (Vercel or static export).

Tracking conventions

  • Every sprint → HTML plan in docs/sprint-NNN.html
  • Every sprint → HTML review in docs/sprint-NNN-review.html
  • Tasks use prefix SC-NNN (numbered sequentially across all sprints)
  • Each task has acceptance criteria and is marked Planned, Done, or Deferred

How to read this roadmap

Sprints are sequential — each depends on the previous. If scope changes, tasks may move between sprints but the order of themes stays the same unless explicitly reprioritized.
