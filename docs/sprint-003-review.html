Architecture decisions

  • Boss extends Enemy-like behavior but is a standalone class with phase-based AI state machine
  • EnemyProjectile is simpler than Player Projectile — no trail, no damage numbers
  • Passive items stored as Set<PassiveItemType> on Player — cheap to check, easy to extend
  • Tri-shot modifies fire logic in DungeonScene (3 projectiles spread by 5 degrees), not in Player
  • Minimap coordinates are world-pixel → minimap-pixel scaled, rooms tracked by index in discoveredRooms Set
  • Floor themes selected by Math.max floor >= theme.floor — last applicable theme wins
  • Boss exit: exitSprite created dynamically (not from map tile) after boss death at item spawn location
  • Enemy scaling applied in both API route (real) and DungeonScene (fallback) for consistency
