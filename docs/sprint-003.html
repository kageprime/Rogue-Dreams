Sprint 3: Content Depth

Epic: EPIC-003 Goal: More enemy types, bosses, items, map features Status: Planned

Sprint 2 made the game feel good. Sprint 3 makes it deep — ranged enemies, boss fights, item pickups, a minimap, and visual variety so every run is different.

Tasks

SC-301 — Ranged enemies

  • New EnemyProjectile entity class
  • Ranged AI: maintain distance, fire on cooldown
  • Enemy projectiles: red/orange, wall collision, player-damaging
  • Add ranged enemy types to API pool
Acceptance: Ranged enemies fire projectiles, keep distance, can be killed. Players dodge or use walls.

SC-302 — Boss rooms

  • Every 3rd floor spawns a boss (3x HP, 48px, charge + barrage + slam phases)
  • Boss arena room, exit locked until boss dies
  • Boss HP bar in GameUI, reward drop on death
Acceptance: Boss encounters with visible HP bar, multiple attack types, reward on kill.

SC-303 — Weapon pickups

  • Weapons as floor items from FloorData.items
  • Walk over to equip, notification + sound
  • Glowing visual indicator
Acceptance: Weapons appear as pickups; equipping shows notification and swaps weapon.

SC-304 — Passive items

  • Boots of Speed (+30%), Shield (+2 max HP, -1 dmg), Tri-Shot (3 projectiles)
  • Stored on Player, modifiers applied in update
  • HUD shows active item icons
Acceptance: Passive items visibly affect gameplay.

SC-305 — Minimap

  • 160x120px overlay in top-right corner
  • Rooms as rectangles, player dot, exit marker, fog of war
  • Phaser Graphics in GameUI scene
Acceptance: Minimap shows explored rooms, player, exit. Unexplored areas hidden.

SC-306 — Floor themes

  • 5 palettes: Dungeon, Cave, Ice, Fire, Void
  • Applied in renderMap() via floor number
Acceptance: Different floor depths have distinct color palettes.

SC-307 — Enemy scaling

  • Count: 2 + floor/2, HP: base + floor, speed scales
  • Elite variants (10%): 2x HP, 1.5x dmg, gold tint
  • Mix: at least 1 ranged + 1 melee after floor 2
Acceptance: Higher floors are visibly harder.

Definition of Done

  1. All task ACs met and play-tested
  2. npm run build 0 errors
  3. npm run lint 0 errors, 0 warnings
  4. No regression in Sprint 1-2
  5. Sprint review written
