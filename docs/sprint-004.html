Sprint 4: State Machine + Economy

Epic: EPIC-004 Goal: Proper scene flow, gold economy, shop between floors Status: Planned

Sprint 3 added depth. Sprint 4 adds structure — a proper state machine with title/pause/game-over screens, a gold-based economy, and a shop that sits between floors. The game finally feels like a complete product, not just a prototype.

Tasks

SC-401 — TitleScene

  • Phaser scene replacing the React title screen
  • Animated ASCII art logo (scale pulse)
  • Blinking "PRESS ENTER TO START" prompt
  • Controls hint text at bottom
  • ESC key shows quit confirmation in browser
  • On ENTER → BootScene (texture gen) → DungeonScene (floor 1)
Acceptance: Title screen appears on load after boot. ENTER starts a new run.

SC-402 — PauseScene

  • ESC toggles pause overlay in DungeonScene
  • Semi-transparent dark overlay background
  • "PAUSED" header, "Resume" and "Quit Run" options
  • Resume → DungeonScene resumes
  • Quit → back to TitleScene, registry cleared
  • Mute/unmute toggle shown
Acceptance: ESC pauses/unpauses. Quit returns to title.

SC-403 — GameOverScene

  • Death triggers GameOverScene instead of restarting BootScene
  • Shows: floor reached, score, gold collected, enemies killed
  • "GAME OVER" header with death animation (fade in)
  • ENTER to restart new run
  • ESC to return to TitleScene
  • Statistics from registry (accumulated across floors in the run)
Acceptance: Death shows stats. ENTER restarts. ESC goes to title.

SC-404 — Gold system

  • Enemies drop 1-3 gold on death
  • Gold auto-collected (no walking over needed), floating "+N gold" text
  • Gold tracked on DungeonScene, stored in registry per run
  • Gold counter in GameUI (top-left, below items)
  • Gold persists across floors within a run
  • Sound effect on gold pickup (short coin jingle)
Acceptance: Gold drops from enemies, accumulates, shows in HUD, persists through floors and shop.

SC-405 — ShopScene

  • Entered after reaching exit on any floor (after floor 1)
  • Background: dark with cyberpunk grid aesthetic
  • Three item slots: Health Potion (3g), Weapon Upgrade (5g), Random Passive (7g)
  • Click to buy, item grays out if purchased or unaffordable
  • "Not enough gold" feedback on insufficient funds
  • SPACE/ENTER to leave shop and start next floor
  • Sound effects for buy and enter/leave
Acceptance: Shop shows between floors. Items buyable and affect next floor. Gold persists.

Definition of Done

  1. All task ACs met and play-tested

  3. npm run lint 0 errors, 0 warnings
  4. No regression in Sprint 1-3
  5. Sprint review written
