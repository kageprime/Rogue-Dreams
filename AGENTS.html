Rogue Dreams — Agent Instructions

Project

Infinite AI-generated retro roguelite.

  • Stack: Next.js (monorepo) + Phaser.js + LLM generation
  • Turn model: Real-time (Binding of Isaac style)
  • Visuals: LLM describes → sprite recipes (composable pixel templates, no image gen API)
  • Platform: Desktop web only

Workflow: PM + Sprints

  • All PM artifacts in docs/ as HTML (sprint plans, tickets, specs, status reports)
  • Everything traces back to a sprint or epic
  • Read existing HTML specs in docs/ before starting work on any feature

Architecture

rogue-dreams/
├── pages/              # Next.js pages (index, game)
├── game/               # Phaser game logic
│   ├── scenes/         # Boot, Dungeon, UI
│   ├── generation/     # LLM prompts, parsers, sprite mapping
│   ├── entities/       # Player, Enemy, Projectile, Item
│   └── systems/        # Collision, Combat, Camera
├── api/generate/       # LLM generation endpoint
├── docs/               # PM artifacts (HTML)
└── public/sprites/     # Base tile/UI sprites

Commands

npm run dev        # Next.js dev server
npm run build      # production build
npm run lint       # lint

Conventions

  • LLM prompt templates → game/generation/prompt.ts
  • LLM output parsed and validated before feeding game engine
  • Sprite recipes: JSON composable from body/shape/color/eyes templates
  • New features include corresponding HTML spec in docs/
